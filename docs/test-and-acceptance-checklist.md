# 测试与验收清单

## 1. 自动化测试

### 1.1 方案数据与映射

- [ ] 加载合法的小鹤方案数据。
- [ ] 拒绝缺失必填字段、未知键名、重复映射或空音节表的数据。
- [ ] 拒绝不能由映射表达的合法音节或不一致的零声母规则。
- [ ] 验证常见声母和韵母映射，例如 `zh -> v`、`ang -> h`。

### 1.2 候选查询与状态机

- [ ] 空闲状态输入有效首键后，仅返回可组成合法音节的第二键。
- [ ] 普通声母的候选集合正确。
- [ ] 零声母音节的候选集合正确。
- [ ] 空闲状态输入无效首键后，产生无效反馈并立即回到空闲。
- [ ] 等待第二键状态输入任意字母后立即重置，不输出完成音节。
- [ ] 等待第二键状态的 `Backspace` 和 `Escape` 均会重置。
- [ ] 空格不改变当前状态。
- [ ] 等待第二键状态不随时间自动重置。

### 1.3 前端组件

- [ ] 仅渲染 26 个字母键，且按三行 QWERTY 排列。
- [ ] 每个键帽显示大写字母和可用的方案映射。
- [ ] 有效首键后只高亮候选第二键，其他字母键灰化。
- [ ] 不额外高亮首键，不显示已完成拼音，不播放正常按键动画。
- [ ] 无效首键显示短暂无效状态。
- [ ] `70%` 与 `160%` 缩放边界下键帽文字仍可读。

### 1.4 Rust 原生层

- [ ] ANSI QWERTY 的受支持字母键被归一化为小写 `letter` 事件。
- [ ] `Backspace`、`Escape`、空格被归一化为约定事件。
- [ ] 其他按键不会传递给前端。
- [ ] 权限重复检查不会重复注册监听器。
- [ ] 权限状态变化能正确切换监听启停状态。

## 2. macOS 手动验收

### 2.1 首次使用与权限

- [ ] 首次启动显示悬浮键盘；已授权时开始监听。
- [ ] 未授权时不监听，设置中显示明确说明并可打开系统设置。
- [ ] 在系统设置授予权限后，回到应用、打开设置或点击重新检测可恢复监听，无需重启。
- [ ] 撤销权限后，应用停止监听并回到权限降级模式。

### 2.2 窗口与菜单栏

- [ ] 悬浮窗口无边框、透明、默认置顶，不抢键盘焦点，也不阻挡鼠标点击下方应用。
- [ ] 从菜单栏可以显示、隐藏悬浮窗口，打开设置，暂停/恢复监听和退出应用。
- [ ] 关闭悬浮窗口或设置窗口后，应用仍在菜单栏运行。
- [ ] 仅菜单栏“退出”会结束应用进程。
- [ ] 位置、缩放、透明度、置顶和暂停状态在重启后恢复。

### 2.3 多显示器与显示缩放

- [ ] 在主显示器和外接显示器上均可保存并恢复可见位置。
- [ ] 断开保存窗口所在的显示器后，应用将键盘恢复到主显示器右下角。
- [ ] 分辨率变化后，窗口仍处于可见工作区域。
- [ ] 在缩放最小值和最大值下，键帽文字清晰且不重叠。

### 2.4 隐私边界

- [ ] 应用不影响其他应用的正常文字输入。
- [ ] 应用不显示、写入、传输或保留完整输入内容和按键历史。
- [ ] 对非受支持按键不产生双拼状态变化。
