# 领域文档

工程技能在探索代码库时应当如何消费本仓库的领域文档。

## 在探索之前，阅读这些文件

- 仓库根目录的 `CONTEXT.md`。
- `docs/adr/` 中与即将工作区域相关的 ADR。

若这些文件不存在，静默继续；由 `/domain-modeling` 在术语或决策实际需要解决时创建。

## 文件结构

本仓库使用单上下文布局：

```
/
├── CONTEXT.md
├── docs/
│   └── adr/
└── src/
```

## 使用术语表的词汇

在 issue 标题、重构提案、假设和测试名称中使用 `CONTEXT.md` 已定义的术语，避免使用其中明确排除的同义词。若需要尚未定义的概念，应交由 `/domain-modeling` 判断并记录。

## 标记 ADR 冲突

输出与既有 ADR 冲突时必须明确指出冲突及重新讨论的原因，不得静默覆盖。
