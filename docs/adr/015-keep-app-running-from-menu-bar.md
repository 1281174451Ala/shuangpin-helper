# ADR 015：以菜单栏作为应用生命周期入口

## 状态

已接受

## 背景

双拼辅助工具应常驻后台。用户可能误关闭设置窗口或悬浮窗口，但仍希望随时从菜单栏恢复辅助功能。

## 决策

关闭悬浮窗口、点击虚拟键盘 `EXIT`、通过菜单栏隐藏窗口或使用 `Command + H` 时，应用统一隐藏主窗口、重置双拼状态，并暂停全局按键事件转发；应用继续在菜单栏运行。再次通过菜单栏、Dock 或重复启动应用显示窗口时，若已有辅助功能权限则自动恢复按键转发。只有用户通过菜单栏的“退出”操作时，应用进程才真正结束。

## 影响

应用行为符合常驻 macOS 工具的预期。原生窗口关闭事件及所有隐藏入口必须收敛到同一隐藏流程，避免后台继续处理按键；菜单栏菜单需要明确区分显示/隐藏和退出操作。
