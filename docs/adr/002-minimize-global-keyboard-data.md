# ADR 002：最小化全局键盘数据

## 状态

已接受

## 背景

全局键盘监听需要 macOS 辅助功能权限，若处理不当可能暴露用户敏感输入。本应用是学习辅助工具，不是输入法或键盘记录器。

## 决策

仅处理字母键、`Backspace`、`Escape` 和空格。在内存中最多保留当前两键双拼序列，以驱动视觉反馈；不写入、不传输，也不以其他方式持久化观察到的键盘事件或其内容。

## 影响

应用的权限范围清晰且可解释，并避免保留敏感数据。需要输入历史的功能（如错误分析）必须另行作出产品决策并设计显式同意流程。暂停监听是菜单栏中的次要控制项，而非主要隐私保障；MVP 不提供全局暂停快捷键。
