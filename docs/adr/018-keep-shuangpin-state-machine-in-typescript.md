# ADR 018：双拼状态机保留在 TypeScript 层

## 状态

已接受

## 背景

全局监听是 macOS 原生职责，而双拼候选计算和界面状态属于跨平台的产品逻辑。将两者耦合在 Rust 中会增加迭代和单元测试成本。

## 决策

Rust 全局监听层只将受支持的按键归一化后发送给前端，例如 `letter: "d"`、`backspace`、`escape` 和 `space`。React/TypeScript 中的纯状态机负责双拼序列、候选计算和视觉状态。

## 影响

大部分业务规则可通过前端单元测试验证，原生层保持轻量。事件协议需要保持稳定并补充 Rust 侧归一化测试，以保证前端能安全处理所有事件。
