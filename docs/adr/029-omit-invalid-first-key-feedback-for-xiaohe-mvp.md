# ADR 029：小鹤 MVP 不实现无效首键反馈

## 状态

已接受

## 背景

Rust 仅向前端转发未修饰的小写 `a-z` 字母事件。已审定的小鹤数据表明，每个字母都能作为首键产生至少一个合法第二键候选。因此，无效首键反馈在当前 MVP 的正常事件路径中不可达。

## 决策

小鹤 MVP 的状态机仅保留空闲和等待第二键两种状态，不实现无效首键的视觉反馈、计时器或过期事件。小鹤专属测试须校验全部 26 个小写字母都具有非空候选集合；通用配置校验允许未来方案不支持部分首键。

ADR 007 保留为历史和未来方案的决策依据。若新增方案包含候选集合为空的受支持首键，或扩大事件协议以允许其他字母事件进入状态机，必须重新评估并恢复无效首键反馈。

## 影响

当前状态机和前端测试无需包含不可达的无效状态分支，状态模型保持精简。新增双拼方案时，候选索引测试必须首先确认是否存在无效首键；存在时不能沿用本 ADR 的简化结论。
