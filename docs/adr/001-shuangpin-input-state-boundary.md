# ADR 001：双拼输入状态边界

## 状态

已接受

## 背景

辅助工具需要监听全局键盘事件，但不得修改用户输入的文本，也不能依赖当前输入法的拼音组合状态。因此，需要一个可预测的边界来判断两键双拼编码何时开始和结束。

## 决策

将字母键按本地两键双拼序列处理：

- 第一个字母进入“等待第二键”状态。
- 下一个字母完成该序列；无论组合有效或无效，状态均立即重置。
- `Backspace` 和 `Escape` 取消等待中的第一键。
- 空格不参与双拼序列。

## 影响

界面保持即时响应，且不依赖具体输入法。工具偶尔会对并非中文输入意图的字母组合提供视觉反馈；这符合学习型 MVP 的定位，后续可通过启停控制或输入模式筛选改善。
